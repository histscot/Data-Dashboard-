# Carrier Performance Dashboard (mobile web app)

Single-file, phone-friendly carrier performance dashboard. `index.html` is the whole app (data included);
open it in a browser, or enable **Settings → Pages → Deploy from branch → `main` / root** to host it, then
use *Add to Home Screen* on a phone to install it.

To update: replace `index.html` with the newest mobile build (keep the `<link rel="manifest">` / icon lines in `<head>`).
